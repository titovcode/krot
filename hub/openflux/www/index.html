OpenFlux Exit Node

Выходная нода OpenFlux. Телефон с OpenFluxAndroid туннелирует трафик через выбранный транспорт на этот роутер.

Загрузка...

URL с бинарниками openflux-linux-*. Пусто = попытка скачать из релиза openflux-0.1.0 репозитория модуля. Если вставил ссылку на страницу релиза (/releases/tag/...), она автоматически исправится на /releases/download/.... Нет бинарника — нажми «Скачать бинарник».

В l3-режиме ядро шлёт TCP RST на чужие соединения и рвёт туннель. Модуль ставит nft-таблицу krot_openflux (или iptables-цепочку KROT_OPENFLUX).

Как подключить телефон

1. Установи OpenFluxAndroid на телефон

2. В приложении выбери тот же транспорт и введи те же параметры (URL/токен/комнату)

3. Нажми «Подключить»

Бинарник должен лежать в /opt/openflux/openflux. Собери: sh hub/openflux/build-binaries.sh, скопируй: scp dist/openflux-linux-arm64 root@192.168.1.1:/tmp/openflux, затем нажми «Обновить» в Hub.

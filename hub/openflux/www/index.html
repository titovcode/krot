OpenFlux Exit Node

Выходная нода OpenFlux на роутере. Телефон с приложением OpenFluxAndroid туннелирует трафик через разрешённые транспорты (Yandex Docs/Volga, MAX, Cups.online, Mail.ru) на роутер и выходит через его WAN.

… Логи: logread -e krot-openflux

Настройки

URL, где лежат openflux-linux- файлы. Пусто = попытка скачать из релизов upstream (Linux-сборки там пока не публикуются). Соберите бинарник скриптом hub/openflux/build-binaries.sh и выложите.

В l3-режиме ядро шлёт TCP RST на чужие соединения и рвёт туннель (см. issue #44). Модуль ставит nft-правило krot_openflux (или iptables KROT_OPENFLUX).

Как это работает

  1. Получите бинарник openflux-linux-: соберите hub/openflux/build-binaries.sh, выложите по HTTPS и укажите bin_base выше (затем «Перезапустить»), либо скопируйте на роутер: scp openflux-linux- root@<router>:/opt/openflux/openflux.
  2. Добавьте инстанс: выберите транспорт и вставьте его URL/токен (Yandex doc URL, MAX token+uid, base64 комнат Cups.online).
  3. В l3-режиме роутер сам подавляет kernel-RST; в l4 работает без root, но медленнее.
  4. На телефоне в OpenFluxAndroid подключитесь с теми же transport/url/codec.

OpenFlux Exit Node

Выходная нода OpenFlux на роутере. Телефон с приложением OpenFluxAndroid туннелирует трафик через разрешённые транспорты и выходит через WAN этого роутера.

Загрузка...

1. Установи OpenFluxAndroid на телефон.

2. В приложении: Добавить — по QR/скан — отсканируй код выше (достаточно один раз, дома).

3. Нажми «Подключить». Работает в любой сети, где доступен выбранный транспорт.

Настройка не завершена.

1. Собери бинарник: sh hub/openflux/build-binaries.sh (нужен Go)

2. Скопируй на роутер: scp dist/openflux-linux-arm64 root@192.168.1.1:/tmp/openflux

3. Нажми «Обновить» в панели Hub или выполни: sh /www/cgi-bin/openflux

4. Добавь инстанс в /etc/config/krot_openflux (см. комментарии в файле)
